# GitHub Pages 名刺ページ

中小企業の経理フロー改善・AI活用支援用の、静的HTML名刺ページです。

## ファイル構成

- `index.html`
- `style.css`

## 公開前に置き換える箇所

1. メールアドレス  
   `your-email@example.com`

2. GitHub URL  
   `https://github.com/`

3. 必要に応じて、note LP・GoogleフォームURL

## GitHub Pages 公開手順

1. GitHubで `あなたのGitHubユーザー名.github.io` という名前のリポジトリを作成
2. このフォルダ内の `index.html` と `style.css` をアップロード
3. Settings → Pages で公開状態を確認
4. `https://あなたのGitHubユーザー名.github.io/` にアクセス
5. URLをQRコード化して、紙名刺・スマホ提示用に利用
